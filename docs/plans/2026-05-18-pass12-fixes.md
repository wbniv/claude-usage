# Fix all 13 findings from pass-12 code review

## Context

The [2026-05-18 pass-12 exhaustive code review](/home/will/SRC/claude-usage/docs/investigations/2026-05-18-code-review-pass12.md) surfaced 13 findings against the `0.11.0` release: 1 High, 5 Medium, 4 Low, 3 Informational. None are crashes (pass 11's R-1 critical is verified resolved), but they cluster around three structural patterns:

1. **Cross-installer parity drift** (I-2, K-3, K-4) — `install.sh`, `build-deb.sh`, and `claude-usage-setup` each implement install-time chores slightly differently. Pass 11's `reset-failed` fix landed only in `claude-usage-setup`; `install.sh` is still broken on upgrade-from-failed-state.
2. **Subtle GJS lifecycle bugs** (E-10, E-11, J-2) — found by deep tracing of `_updateDisplay` re-entry and `GLib.timeout_add_seconds` source-ID handling.
3. **Silent drift between components** (V-1, S-5, S-6, A-1) — Chrome extension can run an older payload shape against a newer server with no visible signal; validator accepts unbounded extras; cache has no schema version.

This change ships them all in a single bundled fix matching the pass-11 pattern, bumps to `0.11.1`, and adds the missing pytest coverage for `_validate()`. Outcome: `0.11.1` closes every finding the pass-12 review opened, the next review pass starts from a clean slate.
