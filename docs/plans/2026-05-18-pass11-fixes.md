## CI structure note

`packaging/test-deb-verify.sh` is unchanged — still does static checks (file presence, syntax, `apt-get remove`) inside Docker. The live-systemd probe lives in the new `packaging/test-deb-live.sh` which runs on a real systemd host (GH Actions bare runner). This separation keeps each script's contract tight and avoids needing a systemd-in-Docker setup.

Open caveat: GH Actions does not yet offer a `ubuntu-25.10` runner, so 25.10 capability behavior is verified locally only until either upstream adds the runner or a self-hosted 25.10 runner is added. The Docker matrix still gates 25.10 *static* compatibility (dependency resolution, file paths, syntax).
